Yazi Usage

Navigation
- Move: C-n / C-p (down/up)
- Fast move: C-d / C-u (down/up 5)
- Tabs: t (new), 1..9 (switch), [ / ] (prev/next)

File actions
- Create: a
- Rename: r
- Copy: y y
- Cut: y n
- Paste: p (force: P)
- Trash: d d
- Delete permanently: D

Search and filter
- Find: /
- Find previous: ?
- Next/prev match: n / N
- Filter: f

Selection
- Toggle selection: Space
- Visual mode: v (unset: V)
- Select all: C-a
- Invert selection: C-r

Openers
- Edit uses $EDITOR
- Open/reveal uses macOS open and open -R

Notes
- Image previews use magick; text uses bat; markdown uses glow; CSV uses miller; JSON uses jq.

Full docs: docs/tools/yazi.md
