Yazi

Purpose
- Fast TUI file manager with previews and custom keymap.

Navigation
- Down/up: C-n / C-p
- Fast down/up: C-d / C-u (5 lines)
- Tabs: t (new), 1..9 (switch), [ / ] (prev/next)

File actions
- Create: a
- Rename: r
- Copy: y y
- Cut: y n
- Paste: p (force: P)
- Trash: d d
- Delete permanently: D

Search and filter
- Find: /
- Find previous: ?
- Next/prev match: n / N
- Filter: f

Selection
- Toggle selection: Space
- Visual mode: v (unset: V)
- Select all: C-a
- Invert selection: C-r

Openers
- Edit uses $EDITOR
- Open uses macOS open
- Reveal uses open -R

Previews
- Images: magick
- Text: bat
- Markdown: glow
- CSV: miller
- JSON: jq
